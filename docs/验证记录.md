- 16 项 Node.js 核心检查通过：完整示例、锁定大纲缺项、题型/题量/综合题不足、来源与反向引用、完整解析、旧版兼容、客观判分与简答自评、乱序分卷、重复/冲突分卷、失败不覆盖、课程更新、错题/间隔复习及备份恢复、错误 JSON 与 LaTeX 拒绝。
- 完整示例：6 个知识点、36 道题、265 处公式通过 KaTeX 检查；三卷示例合并后结果相同。
- GitHub Actions macOS/Xcode 实际 Release 设备编译成功；产物中的可执行文件识别为 Mach-O 64-bit arm64，包含 Web 界面、题库、引擎、完整提示词与离线字体。IPA 的 SHA-256 与构建端校验文件一致。
- 浏览器操作验证：新课程 JSON 导入、作答错误反馈、回看知识点再返回原题后保留选择与解析、刷新后记录仍保留、24px 字号设置生效。

- 小屏公式测试：行内长公式、独立长公式、矩阵、分式均已渲染，无 KaTeX 错误；独立公式内容约 664px，容器约 207px 时内部横向滚动，页面仍保持自身宽度。

## 仍需实际设备验证
